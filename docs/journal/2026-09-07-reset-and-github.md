# איפוס הפרויקט ומעבר ל-Git

- **תאריך:** 7 בספטמבר 2026
- **מי:** הסוכן הראשי (Claude), לפי הנחיית תומר

## מה נעשה

1. **איפוס.** תומר החליט שהפרויקט מתמקד באפליקציית ה-Wellbeing בלבד.
   הוסרו: אפיון קודם למוצר אחר, אפיון Wellbeing ישן שסתר את האפיון הפעיל
   בשאלת ערוץ התזכורות, כיווני עיצוב, רעיונות ורשומות יומן ישנות.
   `docs/` נשאר עם האפיון הפעיל והסטאק בלבד, והסטאק נכתב מחדש סביב
   ה-Wellbeing.
2. **GitHub.** הפרויקט הועלה כריפו ציבורי:
   https://github.com/TomerAnliza/wellbeing-app, בחשבון של
   tomer@analiza-college.co.il. הקומיט הראשון מכיל את המצב אחרי האיפוס.
3. **נוהל Git.** נכתב [git-workflow.md](../git-workflow.md), ופרטי הגישה
   נכנסו לראש `AGENTS.md`, כדי שיהיו הדבר הראשון שכל סוכן רואה.

## למה

- **מקור אמת אחד.** שני אפיונים סותרים גורמים לסוכנים לבנות שני מוצרים.
  נשאר אחד, והוא מוצהר כגובר.
- **Git במקום Dropbox.** כמה סוכנים ובני אדם עובדים במקביל. Dropbox לא
  מספר מי שינה מה ולמה; Git כן. מעכשיו עבודה שלא נדחפה לא קיימת עבור
  הצוות.
- **פרטי גישה בלי סודות.** במסמכים מופיעים הריפו, החשבון והענף. הטוקן
  נשאר ב-keyring של `gh`, ו-`.gitignore` חוסם `.env`.

## מה הלאה

- תומר מוסר את העיצוב החדש. הוא נכנס ל-`design/` בקומיט משלו עם רשומת יומן.
- רק אחרי העיצוב: תוכנית מימוש, חוות דעת של צחי, ואז קוד בענף `feature/`.
