# Lec6 — אפליקציית Wellbeing ותזכורות אישיות

פרויקט משותף לעבודה של כמה סוכני AI (Claude, Codex ועוד) ובני אדם יחד.

**מה בונים:** אפליקציית Web שבה משתמש מגדיר עד שלושה הרגלים (שינה, אכילה
בזמן, כושר), מקבל תזכורת WhatsApp בזמן שבחר, מסמן "עשיתי / לא עשיתי"
באתר, ורואה את ההתמדה שלו לאורך זמן.

העיקרון: **מסמכים מפורטים לפני קוד**, וכל הקוד מתועד במסמכים ברורים
לבני אדם תחת [docs/](docs/).
